# 03 docker：Dockerfile / compose

## 內容

把 01 的 todo 專案容器化，部署到 02 那兩台 VM。應用在跳板機，資料庫在內網機。在自己筆電上 compose 起得來不算完成。

範圍：

- 安裝 docker、docker rootless，以及兩者差別
- Dockerfile：打包、多階段建置瘦身、`.dockerignore`
- 離線安裝檔：`docker save` → 拷貝到無網路機器 → `docker load`
- compose：`build`、`network`、`volume`、環境變數、`depends_on` 與 `condition`、`healthcheck`

rootless 只是對照，不帶進 05。但要能回答「rootless 到底防住了什麼」，這題會口頭問。

Go 單階段 image 會從 20MB 變成 1GB 以上，而且功能完全正常。

---

## 硬性條件

- todo 專案的資料庫遷移要是獨立的一次性指令。寫進 `serve` 啟動流程的話現在回去改
- 三種執行單位共用同一個映像檔，靠 `command` 區分：

```
migrate:   command: ["migrate"]                      restart: "no"
serve:     command: ["serve", "--port", "8080"]      restart: unless-stopped
worker:    command: ["worker", "event"]              restart: unless-stopped
```

- 一定要實際部署到 VM
- rootless 要跑過一次
